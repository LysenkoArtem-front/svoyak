# Свояк — помощник ведущего

Одностраничное веб-приложение для ведущего игры «Свояк» (по мотивам передачи): раунды с категориями и вопросами, модификаторы, секретные вопросы и финал со ставками. Работает целиком на одном устройстве, без сервера и регистрации.

**Играть:** приложение публикуется через GitHub Pages — адрес появится в настройках репозитория (Settings → Pages), обычно `https://<имя-аккаунта>.github.io/svoyak/`.

## Что умеет

- **Раунды 1–3** — сетка «категории × номиналы»: клик по номиналу открывает вопрос, кнопки «Верно/Неверно» начисляют ±номинал игроку.
- **Модификаторы вопросов**:
  - «+ на −» — верный ответ снимает баллы, неверный приносит;
  - «приблизительно» — до конца раунда можно отвечать приблизительно (индикатор на сетке);
  - «попросить баллы» — ведущий назначает любую сумму, включая отрицательную.
- **Секретные вопросы** — назначаются конкретному игроку, отвечает только он.
- **Финал** — игроки по кругу убирают темы → закрытые ставки от 1 до all-in (ввод скрыт точками) → вопрос оставшейся темы → закрытые ответы → раскрытие и подсчёт ±ставка.
- **Отмена** — любая ошибка нажатия откатывается кнопкой «Отменить» в шапке.
- **Автосохранение** — состояние игры хранится в localStorage: перезагрузка и закрытие браузера ничего не теряют.
- **Итоги** — таблица с медалями и кнопкой «Сыграть ещё раз» (те же игроки и пак, счёт в ноль).

## Пак вопросов

Пак — JSON-файл. Проще всего собрать его во встроенном редакторе («Редактор пака» на экране настройки) или загрузить пример и поправить под себя.

Формат:

```json
{
  "rounds": [
    {
      "categories": [
        {
          "name": "Название категории",
          "questions": [
            {
              "value": 100,
              "text": "Текст вопроса",
              "answer": "Ответ",
              "modifier": "none | invert | approx | ask",
              "secret": false
            }
          ]
        }
      ]
    }
  ],
  "final": {
    "topics": [
      { "name": "Тема финала", "question": { "text": "Вопрос", "answer": "Ответ" } }
    ]
  }
}
```

- Раундов 1–3, в каждом 1+ категорий с любым числом вопросов; темы финала — минимум 2, у каждой свой вопрос (играет та, что останется).
- Тему финала можно задать и просто строкой: `"topics": ["Тема", ...]` — вопрос впишете в редакторе.
- Импорт и экспорт — кнопками на экране настройки; валидация подскажет, что не так.

## Запуск локально

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
node dev-server.mjs        # http://127.0.0.1:8437, без кэширования — удобно при правках
# или
python3 -m http.server 8000
```

## Публикация и обновление

Приложение — статичные файлы, деплой это просто `git push` в этот репозиторий (GitHub Pages раздаёт ветку `main`). Обновили файлы — закоммитили и запушили, через минуту сайт обновился.

Запасной вариант — [Cloudflare Pages](https://pages.cloudflare.com/): создание проекта → прямая загрузка папки (drag & drop), адрес вида `svoyak.pages.dev`, свой домен не нужен.

## Структура проекта

```
index.html            — разметка и экраны
css/style.css         — стили
js/state.js           — состояние игры, localStorage, отмена действий
js/pack.js            — формат пака, валидация, встроенный редактор
js/board.js           — сетка раундов 1–3 и экран вопроса
js/final.js           — финал: выбывание, ставки, ответы, раскрытие
js/app.js             — навигация, настройка игры, итоги
js/util.js            — мелкие помощники
data/example-pack.json — пример пака (36 вопросов)
dev-server.mjs        — локальный сервер разработки без кэширования
```
